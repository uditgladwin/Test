# Health and Happiness Presentation Generator

This Python script generates a PowerPoint presentation on the topic "Effect of Health on Happiness".

## Description

The script creates a comprehensive PPTX presentation that explores the relationship between health and happiness, covering:

1. **Title Slide**: Main presentation title
2. **Introduction**: Overview of health-happiness connection
3. **Physical Health Impacts**: Exercise, nutrition, and sleep
4. **Mental Health Impacts**: Stress management, mental well-being, and support
5. **Research Findings & Statistics**: Evidence-based data and studies
6. **Lifestyle Factors**: Diet, exercise, and social connections
7. **Conclusion & Key Takeaways**: Summary and important insights

## Requirements

- Python 3.6+
- python-pptx library

## Installation

Install the required dependency:

```bash
pip install -r requirements.txt
```

## Usage

Run the script to generate the presentation:

```bash
python generate_health_happiness_presentation.py
```

This will create a file named `health_happiness_presentation.pptx` in the current directory.

## Output

The script generates a professionally formatted PowerPoint presentation with:
- Clear, informative content on each slide
- Hierarchical bullet points with proper formatting
- Bold text for key topics
- Consistent styling throughout
